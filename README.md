# T.O.B.I. Academy for Home Assistant

Public Home Assistant distribution metadata for the private **T.O.B.I. Academy** application.

This repository contains no application source code, credentials, university data, session cookies, or private configuration. It only allows Home Assistant to discover and install the public, secret-free container image.

## Installation

1. Open **Settings → Apps → App store** in Home Assistant.
2. Open the app-store menu and choose **Repositories**.
3. Add `https://github.com/MeyTobi/tobi-academy-ha`.
4. Install **T.O.B.I. Academy** and enable **Start on boot**, **Watchdog**, and **Show in sidebar**.

T.O.B.I. Academy is a private personal project and is not an official application of Polizei Hamburg or CampusNet.
